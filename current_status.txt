# Home Rental Website

A full-stack web application for managing apartment rentals, built to showcase modern development skills and help family business.

## 🎯 Project Goals

- **Personal Development**: Improve CV and technical skills for job market
- **Family Business**: Help parents manage their Airbnb apartment more efficiently
- **Cost Reduction**: Provide cheaper alternative to Airbnb with lower commissions
- **Skill Showcase**: Demonstrate full-stack development capabilities

## 🛠 Tech Stack

### Backend
- **Language**: Python
- **Framework**: FastAPI
- **Database**: PostgreSQL (planned)
- **ORM**: SQLAlchemy (planned)
- **Additional Features**: Weather APIs, trip suggestions, AI agents (planned)

### Frontend
- **Framework**: React (planned)
- **Deployment**: GitHub Pages (free hosting)

### DevOps & Tools
- **Containerization**: Docker (planned)
- **Version Control**: Git/GitHub
- **Security**: Authentication & authorization (final phase)
